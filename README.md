# 308 Construction — Unofficial Design Demo

An independent **unofficial website design concept** for 308 Construction, developed for proposal review. Not the official website.

- Official source: https://www.308gc.com/
- Content: derived from published 308 Construction pages, revised to avoid unsupported claims.
- Imagery: illustrative examples, **not photographs of the named projects**.
- Contact/careers forms: demo only; no messages are sent.
- ASK 308: scripted demonstration assistant; **not an AI service**.
- SEO: demo uses `noindex, nofollow`.

## Files
- `index.html` — navigable proof of concept (10 client-side views).
- `assets/css/styles.css` — custom design styles.
- `assets/js/app.js` — routing and interactions.
- `ATREZZO-PROJECT-STATUS.md` — phase and verification ledger.

## Limitations
External fonts, imagery, logo URL, Tailwind CDN and Lucide CDN currently require an internet connection. The logo is loaded from the original website asset. Pages work through a client-side router with shareable `?view=` links, not separate HTML documents. Images still require editorial review, and the layout has not been device-tested. Do not treat this as a production release.

Preview publishing through GitHub Pages requires repository Settings → Pages configuration and final approval.
